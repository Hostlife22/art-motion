# 03 · One frame first, then let it move: four routes

The main method is to design an artistic frame first, and then make the frame move as required. 2026-10-04 All four roads have been run in one project, each with its applicable scenarios.

| Route | Who draws the picture | Who does the action | Actual measurement | When to choose |
|---|---|---|---|---|

## The common first step: a frame draft

No matter which way you go, there is a "right picture" first:
- **With reference film**: Use the "last frame before the transition starts" of the reference film as a reference image and feed it to gpt-image. The prompt reads "Completely maintain the composition, lens, position and size of each item, color matching and brush strokes of the reference image, and only change two things:...". The 50% superposition of the actual measurement and the original film almost coincides with each other pixel by pixel. The composition is locked by reference pictures and does not rely on text to write coordinates.
- **No reference film**: First determine the scene skeleton (standard composition coordinates), and use a screenshot of the skeleton white model as a reference picture.
- **Three Directions Hard Door**: Characters Interpretation (This film: Era Women's Clothes / Same Person Time Travel / Original Head Changing) Three pictures are given on the same frame for people to choose from. Choose the frame with male characters in the original film to make the biggest difference.

Pitfalls in the setting draft (have been through them all):
- Writing underage characters (17 years old) + any words "short skirt" will be reviewed and judged as sexual and the entire page will be rejected. Clothes should always be written in long styles and add "Modest Clothing".
- Part of the coat color is written: "Orange and white cat (orange tabby on the head, back and tail, white muzzle, chest, belly and four paws)". Just writing "orange cat" will make the whole body orange.
- Writing actions ("holding a cup and drinking tea") in the description will overwhelm the postures in the reference picture. To maintain the original posture, just write "Keep the gesture in the reference picture."
- The text to be moved (year, title) is "removed from the model and left as a clean background" and handed over to the code drawing; the decorative text in the drawing is written into the prompt word by word.
- Batch generated images are run serially; for verification, the number of new files in the output directory of the image generating tool = the number of images produced, and there is no date:create of ImageMagick in the PNG info (if there is, it means it was spelled out, not generated by the model).

## The key to Route B: Green screen material retains the original coordinates of the screen

Use the set frame as a reference image, prompt: "Only draw the XX in the reference image... The rest are all flat painted #00FF00, without shadow ground text. The position, size, and orientation are exactly the same as the reference image." The generated characters have already stood on the original screen coordinates. When cutting out the image **Don't cut to the main frame and lose the coordinates** - `scripts/key_green.py`. When cutting, write the upper left corner into sprites.json. When compositing, paste it back according to the original coordinates and align it once.

## The key to route C: the beginning and end are in the same frame

Seedance 2.5/2.0 supports frames2video. The first frame and the last frame are given the same draft → things in the painting move and return to the original composition, and the beginning and end of the clip can be seamlessly transitioned. Prompt structure: ① The lens is completely fixed (no pushing, pulling or zooming) ② The composition/style of painting/color is maintained throughout the whole process, no realism, no addition or deletion of objects, no new text ③ List "what moves in the painting and how to move" item by item (from the dismantled movement list). Generate 5 seconds, take the best 1 second or so, and change the speed according to the rhythm.
Channel: Any Seedance access that supports first and last frames (frames2video) will do. The key point is the prompt itself; video generation is pay-per-view, so try one with a short length first.
